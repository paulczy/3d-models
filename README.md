# 3D Models

3D models I have made or changed. Most are STL or 3MF files, ready to slice and print.

## Models

### RetroTINK 6X stand (`retrotink-6x-stand/`)

A vertical stand for the RetroTINK 6X, based on the RetroTINK 4K stand. The remote slot is changed to fit the new remote that comes with the 6X.

- `rt4k_stand_6x_remote.3mf`
- `rt4k_stand_6x_remote.stl`

Based on: [RetroTINK 4K Vertical Stand](https://www.printables.com/model/669812-retrotink-4k-vertical-stand)

### Pico Micro Mac Quadra case (`pico-micro-mac-quadra-case/`)

A Quadra-style case for the Pico Micro Mac v4.

- `pico-micro-mac-v4-quadra-top.stl` - top shell
- `pico-micro-mac-v4-quadra-bottom-insert.stl` - bottom, for heat-set threaded inserts
- `pico-micro-mac-v4-quadra-bottom-selftap.stl` - bottom, for self-tapping screws

Based on: [Pico Micro Mac Quadra 650 Case](https://www.printables.com/model/1282725-pico-micro-mac-quadra-650-case)
